# AI 노출 측정 도구 시장 — 무엇을 주고 무엇을 안 주는가

> **한 줄** — 기능은 이미 수렴했다. 거의 모든 도구가 같은 여섯 지표를 준다. **차이는 지표가 아니라 "그래서 뭘 해야 하나"로 잇는 방식에서 나고, 어느 도구도 측정의 불확실성은 주지 않는다.**

문항2(PRD)의 기능 범위와 차별점을 근거 있게 잡기 위한 문서다.

---

## 0. 출처의 이해관계를 먼저 밝힌다

이 분야의 자료는 대부분 **팔려는 사람이 쓴다.**

| 종류 | 신뢰 범위 |
|---|---|
| 벤더가 **자기 제품 기능**을 설명한 것 | **1차 출처로 쓸 수 있다.** 자사 기능 목록은 확인 가능한 사실이다 |
| 벤더가 **경쟁사를 평가**한 것 | **근거로 쓰지 않는다.** 이해관계가 명백하다 |
| 벤더가 만든 **비교표·리더보드** | 자사가 상위에 오는 구조인지 본다. 순위는 인용하지 않고 **항목 존재 여부만** 참고한다 |

아래 기능 표는 각 벤더의 자사 서술에서 뽑았고, 순위·우열 주장은 싣지 않는다.

---

## 1. 이미 수렴한 여섯 지표

거의 모든 도구가 아래를 공통으로 제공한다.

| 지표 | 무엇을 재나 |
|---|---|
| **가시성 / 언급률** | AI 응답 중 우리 브랜드가 언급된 비율 |
| **평균 위치** | 답변 안에서 몇 번째로 불리는가 |
| **Share of Voice** | 경쟁사 대비 언급 점유율 |
| **감성(Sentiment)** | AI가 브랜드를 긍정·부정 중 어떻게 서술하나 |
| **인용 출처** | 어떤 도메인·페이지가 근거로 쓰였나 |
| **프롬프트 추적** | 지정한 질문 세트를 주기적으로 실행 |

Peec AI의 제품 페이지가 이 집합을 그대로 열거하고(가시성 · 위치 · 감성 · Share of Voice + 모델 선택 · 경쟁사 추가 · 프롬프트 추적), Evertune은 15개 이상으로 세분해 같은 축을 덮는다.

> **판정 — 지표 자체는 차별점이 아니다.** 새 도구가 "언급률과 SoV를 보여준다"고 하는 것은 시장 진입 요건이지 차별점이 아니다.

## 2. 차별화가 실제로 일어나는 자리

수렴한 여섯 지표 **위에서** 갈린다.

| 축 | 예 (자사 서술 기준) |
|---|---|
| **질의 분해** | Profound의 Query Fanouts — 엔진이 하나의 프롬프트를 여러 하위 질의로 쪼개는 것을 드러내고 그 변형별 점유를 보여준다 |
| **로그 계층** | Profound · Scrunch가 **AI 크롤러 로그**와 방문자 분석을 붙인다. 응답만이 아니라 봇이 실제로 무엇을 가져갔는지 |
| **출처 유형 분류** | Evertune의 Site Category — 인용 도메인을 획득 미디어 / 자사 / 제휴 / 소셜 / 기업 사이트로 분류. **`research/01` §5의 "획득 미디어 우위"를 지표로 만든 것** |
| **수요 추정** | Profound의 Prompt Volumes, Evertune의 Estimated Monthly Prompts — 그 질문을 사람들이 실제로 얼마나 던지는가 |
| **기반 모델 vs 검색** | Evertune이 "base model knowledge vs search-augmented"를 나눠 본다고 표방. `research/01` §5의 2층 구조에 대응 |
| **처방·생성** | Profound가 콘텐츠 생성·최적화를 월 할당량으로 제공. 반면 Otterly는 생성 도구가 없다고 스스로 밝힌다 |

> **판정 — 시장이 "진단"에서 "진단 → 처방 → 적용"으로 이동 중이다.** `research/01` §8.2가 "경로가 끊겨 있다"고 적은 항목이 일부 도구에서 메워지고 있다. **이 빈자리를 차별점으로 쓰려면 확인 시점을 밝혀야 한다.**

## 3. 가격대 — 자기 서비스 플랜 기준

| 도구 | 가격 | 포함 (자사 서술) |
|---|---|---|
| Scrunch | $250/월~ | 7일 무료 체험. Core 플랜은 LLM 4종 · 1개 국가 · 프롬프트 125개로 제한 |
| Profound (Growth) | $399/월 | 프롬프트 100개/월 일간 실행 · 응답 24,000건/월 분석 · 주당 기회 4건 · 콘텐츠 생성 3편 |
| Writesonic (Professional) | $249/월 | 프롬프트 100개 · 답변 엔진 3종. 감성 분석·프롬프트 추천 미포함 |
| Writesonic (Advanced) | $499/월 | 프롬프트 200개 일간 실행 · 엔진 4종 |

> **판정 — 프롬프트 개수와 실행 주기가 가격의 축이다.** 즉 **표본 크기가 곧 비용**이다. 이것이 왜 업계가 반복 측정을 꺼리는지를 설명한다 — 같은 프롬프트를 20번 돌리면 프롬프트 20개를 추적하는 것과 같은 비용이 든다.
>
> **여기가 이 저장소의 주장과 정면으로 만나는 지점이다.** 통계적 신뢰성과 상품 가격 구조가 서로 반대 방향으로 당긴다. 커버리지(프롬프트 수)를 늘리는 편이 팔기 쉽고, 반복(표본 수)을 늘리는 편이 정확하다.

## 4. 아무도 주지 않는 것

`research/01` §4.4에서 확인한 것을 제품 관점으로 다시 적는다.

| 없는 것 | 상태 |
|---|---|
| **신뢰구간** | 자사 지표에 구간을 표시하는 화면을 확인하지 못했다. Evertune이 "confidence intervals on every metric"을 표방하나 **출처가 자사 경쟁 비교 문서라 근거로 쓰지 않는다** |
| **표본 크기 공개** | 대부분 "브랜드당 몇 회 실행하는지"를 공개하지 않는다. Gumshoe가 예외적으로 계산식까지 공개한다 |
| **측정 노이즈와 실제 변화의 구분** | 대시보드가 시계열 그래프를 보여주지만, 그 변동이 노이즈인지 변화인지 판정하는 장치를 확인하지 못했다 |
| **한국어·네이버 AI 브리핑** | 조사 범위의 글로벌 도구에서 네이버 대응을 찾지 못했다 |

> **판정 — "없다"가 아니라 "확인하지 못했다"이다.**
>
> 공개 자료와 제품 페이지만 봤고 실제 대시보드에 로그인해 확인하지 않았다. [`docs/DECISIONS.md`](../docs/DECISIONS.md) D11에서 세운 구분을 여기서도 지킨다. **다만 제품 페이지가 지표를 자랑하는 자리인데 거기에 없다는 것은 약한 신호는 된다** — 팔 만한 기능이면 대개 적는다.

## 6. 우리 맥락에의 시사점 — 문항2로 가는 다리

과제 페르소나가 알고 싶은 것은 **"얼마나(양), 어떻게(질)"** 두 가지다 (과제 원문 기준).

| 페르소나의 질문 | 시장이 주는 것 | 빠진 것 |
|---|---|---|
| **얼마나** 노출되나 | 언급률 · SoV · 평균 위치 — 충분히 성숙 | **그 숫자가 믿을 만한가.** 표본과 구간이 없다 |
| **어떻게** 다뤄지나 | 감성 점수 하나로 뭉뚱그려진다 | 무엇으로 **묘사**되는가, **정확한가**, 어느 **맥락**에서 불리는가 |

> **관찰 — "얼마나"는 시장이 이미 풀었고, "어떻게"는 감성 점수 한 칸에 눌려 있다.** Evertune의 Association Score가 이 방향으로 한 발 나가 있으나 조사 범위에서 일반적이지 않다.
>
> **이것이 기능 2개를 고르는 자리를 만든다.** 다만 **기능 선정은 이 문서의 일이 아니다** — `development-prd`가 문제 정의에서 도출한다. 여기서는 **시장이 어디까지 왔는지**만 확정한다.

**가격 구조에서 온 제약도 PRD에 반영해야 한다** (§3). 반복 측정은 비용이고, 그 비용을 정당화하려면 "구간이 없으면 무엇을 잘못 판단하게 되는가"를 제품이 보여줘야 한다.

## 7. 이 조사가 답하지 못한 것

1. **실제 대시보드 화면** — 제품 페이지와 블로그만 봤다. 로그인해 확인하지 않았으므로 **화면에 무엇이 있는지 단정하지 않는다**
2. **각 도구의 실제 실행 빈도와 표본 수** — 가격 페이지의 "프롬프트 N개/월"이 반복 실행을 포함하는지 불명확하다
3. **국내 도구** — 조사 범위가 글로벌 도구에 치우쳤다. 국내 GEO 도구·대행사가 무엇을 주는지 확인하지 않았다
4. **Evertune의 신뢰구간 표방이 실제 제품에 구현됐는지** — 자사 마케팅 문서 외의 확인이 없다
